# 卡片材质比较

2026-10-18。用户反馈去除白色卡片之后过平，希望研究不同风格，同时保留层次。本版沿用 Dia 比例，研究内层预览块的材质，不改变内容结构。

- A 柔白：近白色柔和表面、轻微接触阴影，形成轻轻浮起的卡片。
- B 透光：半透明底色、细亮边和淡阴影，保留预览卡片的轮廓，同时透出选中底色。默认展示。
- C 内嵌：略暗的内层底色、顶部内阴影和底部亮边，形成浅凹的阅读区域。

三个方案使用相同尺寸、内容、字体和选中底色；内层圆角统一从 5 调整为 8 CSS px。浮层 744 × 140，预览块约 131 × 86，图标仍为 20 × 20。11「五拍」引擎未变。顶部三项按钮为原型比较工具，不属于正式浮层。

旧白卡和柔和版保留，页面顶部提供入口；CSS 方案通过 `?surface=porcelain`、`?surface=frost`、`?surface=inset` 直接访问，支持 `&theme=dark`。仅设计原型，未接入 DSH。

明暗两套需要逐一检查。降低透明度和提高对比度时采用明确实底，优先保障文字可读性。证据与校验清单保存在 `review/`。
