# 五拍 · 整体样式比较

沿用用户选定的 11「五拍」，同一份动效文件没有修改。原版完整保留于 `../session-fivebeat/`，另有独立 ZIP 快照；本页仅用于比较材质、文字层级与密度，未接入 DSH。

| 方向 | 层级与材质 | 浮层高度 |
| --- | --- | --- |
| 原版 | 原文在上、单行标题在下、灰色选中底色 | 136px |
| A · 轻雾 | 原顺序，减少留白，浅雾外层搭配明亮的中性选中底色 | 124px |
| B · 标题在上 | 标题与状态归为顶部一组，标题最多两行，原文预览三行 | 134px |
| C · 紧凑 | 沿用 B 的顶部标题组，原文缩为两行 | 112px |

三种新样式减轻了投影与外边框。浅色的选中项为明亮底色，深色为轻微提亮；均保持原尺寸，不做放大、抬升或新增状态文字。B/C 的长标题使用均衡换行，避免末尾只剩一个字。11 的尺寸仍为 20px。

顶部样式选择器仅属于比较工具，不属于会话浮层。URL 的 `finish` 参数保存选择。完整键盘切换交互沿用此前实现。
