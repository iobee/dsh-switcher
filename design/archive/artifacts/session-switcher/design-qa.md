# 最近会话切换原型检查

2026-10-17，在 Codex 内置浏览器打开本地预览，按实际控件操作检查。默认视口 853 × 880，横向浮层宽度 813 px，五张卡片约 149 × 214 px，完整位于窗口内。用户明确要求横向后，已替换列表设计；初稿存于 before-horizontal/。以下结果仅针对 HTML 原型。

| 检查 | 结果 |
| --- | --- |
| 初始候选 | 显示 5 个示例会话，当前为“打磨键盘导航体验”，预选上一次“节点稳定性与切换策略” |
| 横向卡片 | 5 张卡片位于同一水平行，内容缩略图全部加载；aria-orientation 为 horizontal |
| 左右方向键 | 右键从 s5 选中 s2，左键返回 s5；正文仍停留在 s1 |
| Tab 移动 | 候选变为“左侧栏的焦点与候选状态”，正文标题仍为原会话，列表顺序不变 |
| Shift + Tab | 可回到上一个候选；越过第一项循环到最后一项 |
| Esc 取消 | 浮层关闭，原会话与草稿保留，焦点回到原聊天阅读区 |
| 输入时取消 | 在输入框选中最后一个字后唤起并取消，焦点返回 composer，选区恢复为 20–21，草稿内容一致 |
| 快速往返按钮 | 在 s1 和 s5 之间往返，回到 s1 后草稿仍在 |
| 实际浏览器键盘事件 | 用浏览器键盘 API 输入 Control + Tab，关闭选择态并切到 s5；再次输入返回 s1 |
| Enter 确认 | 选中目标被打开，浮层关闭；返回原会话后仍只有 1 条原始用户消息，未提交草稿 |
| 最近顺序 | 确认和往返后当前在首位、刚离开的会话在第二位，其余相对顺序保持 |
| 明暗外观 | 横向版本两种主题均检查，10 张示例缩略图均已保存；选中态、工作区、状态与操作提示可见，截图见 dark.png、light.png |
| 语法 | switcher.js 与页面主脚本的 node --check 通过 |

初次拷贝时，脚本插入误命中了内嵌网页模板的 body 结束标签；已改为仅插入文档末尾，并重新加载验证。控制台中的两条初始加载错误属于此已修复版本；之后完整交互检查未新增错误。

还未验证：正式插件的会话截图与缩略图缓存、真实 DSH 的原生快捷键桥接、终端和 webview 焦点、快速释放 Ctrl 的原生时序、真实会话归档或权限变化、插件卸载、多窗口、VoiceOver 实际朗读。没有把模拟工具条当作原生按住 Ctrl 的证明。

本轮未改动生产源码或安装 DSH；新增文件仅在 artifacts/session-switcher/。


## 信息卡片修订检查

用户指出截图不能帮助识别后，保留横向布局，改为大标题、工作区、状态与选中项的最近用户输入。以下为修订后重新操作观察的结果：

- Tab 从 s5 移到 s2 时，下方原文变为“上下移动的时候，先不要直接切换会话。”；正文仍为 s1。
- 原地切到缩略图再回信息卡片，选中项保持 s2，原文与候选一致，未触发会话打开。
- Enter 确认后打开 s2；快速往返可返回 s1。
- 明暗外观分别检查并保存为 context-dark.png 与 context-light.png；最终 dark.png / light.png 指向当前信息卡片设计。
- 当前原型视口为 1171 × 880，五张卡片保持同一水平行，标题为 16 px，可读原文为 13 px。旧截图素材不再占据默认卡片面积。

原型内容来源是示例会话里的用户输入与草稿。正式插件的原文读取、无内容时的降级和原生 Ctrl 释放路径仍需集成验证。
