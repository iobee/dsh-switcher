# 动态对照原型检查

2026-10-18。范围为新增设计原型，不代表正式功能验收。

## 已验证

- 六个风格注册且实际渲染，没有浏览器 error / warn。
- 单独模式沿用五项、等大、170 px 高的浮层；无内部标题、计数与按键提示。比较和状态控制在浮层外。
- 玻璃层片画布横向融入页脚，所有卡片仍高 152 px；画布约 135.2 × 18 px，位于卡片内；原文尾部没有覆盖标题区域。
- 局部折射进入卡片表面，标题保留完整宽度；其余四个风格使用 36 × 28 px 局部构件。
- 并排模式使用相同的运行、审批、等回答三项样本，直观看到两种等待的形态差异。
- 状态下拉实际切换运行、审批、回答、新结果、异常、停止；辅助名称、悬停状态和图形数据同步更新。
- 运行 + 草稿同时存在，辅助名称实际为“节点稳定性与切换策略，SharkSwitcher，运行中，有草稿”。
- 静态比较按钮启用后 aria-pressed=true，统一向各绘制器传入 reduced 稳定形态。系统减少动态设置未主动修改，VoiceOver 未验收。
- Tab 移动候选后 Esc 取消，主会话仍为“打磨键盘导航体验”；重新打开后 Tab + Enter，实际模拟打开“左侧栏的焦点与候选状态”。
- 新结果用品牌色，未使用成功绿勾；completionUnread 的成功语义限制在 state-capabilities.md 中记录。
- 录制后检查到页面在后半段被手动切换，因此动图仅采用视图稳定的 45 张运行阶段源帧，采样为 23 帧、约 3.0 秒的 six-styles.gif；同屏分别展示运行、审批、等回答。
- 1280 × 1080 比较截图含全部六方案；辅助视口 override 已 reset。窄窗口沿用固定宽卡片与横向滚动规则，本轮未完成窄窗口人工操作验收。
- 所有新增 JavaScript 语法检查通过。
- 两个保留版的 index.html、switcher.css、switcher.js 均与本轮开始时哈希一致。

## 有限结论

动态图形已经可以比较；“高级感”、状态首次辨识与偏好仍需用户判断。第一轮发现六种都像右下徽记，因此改为玻璃页脚薄层和表面折射两种结构路线，并修正比较样本以包含等回答。没有把所有状态都设计为持续动画。

截图与动图：six-styles.gif、six-styles.png、comparison-light.png、refraction-light.png。comparison-dark.png 记录的是材质改进前的第一轮对照，非当前最终结构。

正式键盘桥接、实时状态订阅和原生桌面背景透出均未接入。
