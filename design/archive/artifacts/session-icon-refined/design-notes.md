# 状态图标精修

入口：`index.html`。顶部「状态演示」展开原尺寸图标对照，可切换候选状态、叠加草稿、静止或播放转换。

用户选择保存的点列版：`../session-signal-dots/index.html`。旧图标版：`../session-signal/index.html`。所有历史方向均保留。

本轮使用 DSH 的中性色、hover、菜单材质角色与原生图标路径，保留水平、紧凑、无内部标题栏和键盘提示栏的切换器。图标固定在标题左侧，卡片不放大。正文保留最后一次输入原文，标题按宿主侧栏习惯单行省略。

| 状态 | 形态 | 动效 |
| --- | --- | --- |
| 运行中 | DSH loading 弧线 | 1.9 秒匀速循环 |
| 待授权 | 护盾，内含暂停短线 | 内线 3.4 秒缓慢变化 |
| 待回答 | 对话气泡，内含问号 | 问号 3.8 秒缓慢变化 |
| 待审阅 | 文档与编辑笔 | 文档内线 3.6 秒缓慢变化 |
| 新结果待看 | 会话图标与未读点 | 首次出现 420ms 后静止 |
| 静置 | 会话图标 | 静止 |
| 草稿 | 编辑图标，或附加笔迹 | 静止，与主状态共存 |

新结果不代表成功，进入该会话后清除未读。没有百分比、虚构阶段或为缺失内容生成的摘要。状态演示为本地 fixtures，不是实际 DSH 状态。
