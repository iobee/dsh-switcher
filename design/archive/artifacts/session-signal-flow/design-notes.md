# 标题旁的横向状态动效

本轮保留 `../session-signal/` 的全部内容，在独立目录探索四种动效。`preserved-baseline.json` 记录原版四个源文件的 SHA-256；交付前复核均未改变。

沿用已选方向：最近用户输入原文、标题旁 20 × 20 图形、横向五项、820 × 144 浮层、128px 卡片、原 hover 中性底色作为选中态。候选不放大，没有新增浮层标题或底部提示。顶部方案选择器及“状态演示”属于设计工具。

| 方案 | 运行中的运动 | 周期 |
| --- | --- | --- |
| A · 掠过 | 三颗点依次从左向右经过，入口和出口渐隐，重置过程不可见。 | 2.05 秒 |
| B · 接力 | 三颗点保留位置，亮度与很小的形变依次向右传递。 | 2.2 秒 |
| C · 流线 | 点在向右移动时伸成圆头短线，在边缘收回、淡出。 | 2.25 秒 |
| D · 汇合 | 三颗点逐渐靠拢，汇成一颗，短暂停留后继续向右离开。 | 2.65 秒 |

四版共用同一组状态形态，便于只比较运行节奏。等待授权时，运动中的点收成两根竖向圆头短线，两侧留微弱点；等待回答、方案确认、新结果、静置及草稿沿用已核查的语义。运行不表示进度百分比，“有新结果”不表示成功。示例来自本地原型，不连接真实 DSH。

方案切换会写入当前页面的 `?motion=pass|relay|ribbon|merge`，可直接打开某一版。所有方案保留标题旁位置、状态颜色和原文截断方式。路径连续插值；减少动态效果或“静帧”会显示稳定形态。浮层关闭时停止其中的动画，页面隐藏时全部停止；顶部对比用的小图形只在页面可见时继续演示。

## 检查记录

- 四版切换后的 URL、选中按钮与主浮层状态一致。
- 五张卡片高度 128px，图形 20px，全部与标题第一行中心对齐，无缩放；选中背景仍为 `rgba(255,255,255,.06)`。
- 检查深色、浅色、等待授权、等待回答和静帧；静帧前后 SVG 路径保持一致。
- 方向键选中另一会话，Enter 打开对应标题；重置恢复原有五会话示例。
- JavaScript 语法检查通过；浏览器控制台未见错误或警告。
- `flow-comparison.gif` 为浏览器真实录制，四版各录制超过一个周期。导出 128 帧、13.75 秒，保留方案选择器与浮层周围的页面作为上下文。
