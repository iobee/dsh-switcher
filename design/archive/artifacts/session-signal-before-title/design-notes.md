# 会话信号 · 设计原型

保留已确认的信息结构：最近一次用户输入原文、会话标题、真实可获得的状态。横向浮层 820 × 168，选中项不放大；外层 7px 内距。所有演示数据来自原有本地示例，不连接当前 DSH 会话。

## 一套图形的不同状态

| 状态 | 形态与节奏 | 语义边界 |
| --- | --- | --- |
| 运行 | 三段短弧沿同一轮廓移动，短弧各自伸展、收拢。 | 不确定进度，不表示百分比，也不推断正在搜索、写代码或调用某个工具。 |
| 等待授权 | 外侧短弧停在两侧，内侧收成两条圆头短线，缓慢呼吸。 | 对应 approval。 |
| 等待回答 | 同一轮廓展开成一个带两点的对话形态。 | 对应 question。 |
| 等待方案确认 | 两侧轮廓与两行短线组合，保持阅读式的静稳节奏。 | 对应 plan-review。 |
| 有新结果 | 轮廓闭合、中心点显现，过渡后保持静止。 | 表示本轮结束且待查看，不等同于执行成功。 |
| 静置 | 图形收去。 | 不为普通闲置会话添加无用装饰。 |
| 草稿 | 静置时呈文字与一笔斜线；有其它活动时保留小斜线。 | 独立维度，可以与运行或等待同时存在。 |

状态依据沿用[已核查的接口说明](../session-status-study/state-capabilities.md)。未来接入时先取 pendingInteraction，再取 running，再取 completionUnread，最后为 idle。草稿来自各会话已缓存输入；不为切换器预加载所有历史。

## 原型体验

- 点击顶部“状态演示”，可改候选会话的状态、叠加草稿、查看静帧或播放转换。该工具栏属于演示，不属于切换浮层。
- Ctrl+Tab 快速往返；按住 Ctrl 延迟展开，继续 Tab 选择，松开提交。方向键、Enter、Esc 可在展开后操作。
- 磨砂与实底可对比；玻璃在浏览器内只模糊背后页面，不代表已实现原生桌面壁纸模糊。
- 减少动态效果时保留各状态的静态差异。关闭浮层、切走页面时停止动画。

## 验证

浏览器检查：暗色与浅色、820 × 168 外层尺寸、五张 152px 高的卡片、候选无缩放、标题全宽且与原文不重叠、Ctrl+Tab 快速切换、方向键选择、Enter 确认、Esc 取消、返回后草稿保留、静帧与动画恢复。控制台未见错误。

`signal-motion.gif` 为真实浏览器录制，保留浮层周围页面作为上下文；约 15.2 秒、91 帧，展示运行、等待授权、等待回答、新结果、静置之间的连续转换。
