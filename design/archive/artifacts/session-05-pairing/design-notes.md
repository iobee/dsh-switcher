# 05 明暗搭配

2026-10-18。基于用户选中的 05 亮色与 07 暗色，做一个独立的材质配对试用。原 05、07、24 款方向及 Like 数据保持原样。

## 设计判断

原 05 暗色卡面为 #34363a，选中背景叠加白色后更亮；较亮的细框和很弱的外阴影，使卡面容易看起来低于选中背景。07 通过较亮的卡面与外阴影表达浮起。

配对不要求明暗模式使用相同的阴影数值，而是保持相同的形状、密度和层次关系。这是针对当前原型的视觉判断。

05 亮色直接引用原始样式。调整后的暗色保留 6px 圆角、744 × 140px 整体尺寸和 11「五拍」动效；卡面采用 07 的 #3c3e42，边线降至白色 4.5%，外阴影使用 0 1px 2px / 22% 和 0 3px 7px / 15%，比 07 的阴影更紧、更轻。不加内阴影或额外渐变。

## 体验入口

- `index.html?mode=raised`：05 亮色固定在上方；下方切换 05 原版、05 轻浮与 07 参考。点击会话或左右方向键同步两个预览的选中项。
- `preview.html?mode=raised&theme=dark`：完整 DSH 场景，继续使用已有 MRU 控制器；顶部可切换三款材质和明暗主题。
- 原方案与 Like：`../session-material-wall/index.html?material=05&theme=dark&view=liked`。

当前仍为本地 HTML 原型。模糊作用于网页内背景，不代表原生桌面材质。

## 验证

两份新 JS 通过语法检查。浏览器验证材质切换、明暗切换、同步选中和完整场景；控制台没有警告或错误。默认尺寸 744 × 140px；668px 窗口内面板 620 × 140px、卡片 143px，横向滚动且页面无横向溢出。提高对比度及减少透明效果时恢复不透明材质并去掉阴影和模糊。

亮色的实际计算结果保持 #fafbfc、6px 圆角、rgba(59,70,83,.114) 边线及原版阴影。暗色计算结果与 refinement.css 相符。
