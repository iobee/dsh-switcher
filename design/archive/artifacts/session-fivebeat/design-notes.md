# 五拍试用版

2026-10-18：用户选择图标墙 11「五拍」，要求保留全部方向后先试用。完整会话切换原型使用该运行图标；五根线的横向位置、粗细、透明度、振幅、相位差、20px 槽位与图标墙一致。玻璃、中性选中底色和紧凑布局沿用已接近 DSH 的版本。其余状态采用用户更喜欢的旧动态图标，运行之外的状态图形尚未重新定稿。

[所有保留版本](../session-design-archive/index.html)包含原 13 组设计的浏览入口，以及 257 个文件的独立 ZIP 快照与 SHA-256 清单。原有文件均未改动。

试用：Ctrl+Tab 快速往返；按住 Ctrl 后继续 Tab 选择，松开切换；方向键、Enter、Esc 可在展开后操作。页面顶部「体验切换」也可展开，状态演示可检查状态转换与草稿共存。这里只使用本地示例会话，尚未接入已安装 DSH。

已验证：快捷键往返、Esc 恢复、草稿保留，六个状态无无效路径；运行图标真实运动，静帧、减少动态效果与关闭浮层后停止。实际浏览器检查浅色窄窗口与暗色宽窗口，控制台未见错误。证据位于 [review/checks.json](review/checks.json) 和 [review/preservation-check.json](review/preservation-check.json)。
