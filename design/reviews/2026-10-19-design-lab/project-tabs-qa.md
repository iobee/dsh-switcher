## 12 次探索的判断

| 方案 | 判断 |
| --- | --- |
| 01 分签 | 原案分区感保留最多，但边界较多，仅作分隔上限。 |
| 02 内签 | 独立标签感强，长项目名可用宽度减少，不主推。 |
| 03 细线 | 足够安静，但削弱用户选中的题签特征。 |
| 04 大字 | 原本单行标题变两行，长标题更早截断，视觉重量偏重。 |
| 05 居中 | 短标题规整，长标题起读位置不稳定，不适合快速扫读。 |
| 06 等宽 | 技术感强，字体节奏与正文分离，不够协调。 |
| 07 压线 | 选中定位明确，但色线与语义状态争夺注意力。 |
| 08 石墨 | 复杂背景下稳定，但不如 B 轻透，不作为默认。 |
| **09 轻签** | **推荐。项目分区、标题、选中态、状态和原话最均衡。** |
| **10 连页** | **备选。整体感更强，分区更弱，适合偏平整的主题。** |
| 11 暖签 | 暖色主题候选，与冷色背景的融合度较弱。 |
| **12 留白** | **备选。扫读最清静，只保留所选原话，牺牲其余预览。** |

这些是设计判断，不是用户偏好测试结果，也不是量化可用性成绩。
